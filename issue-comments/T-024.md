## 초안 작성 (2026-04-22)

### 파일
- `docs/legal/04_sensitive_info_consent.md` — 민감정보 처리 동의서 (얼굴·건강정보 별도 동의)

### 적용 법령
- **개인정보보호법 제23조** (민감정보의 처리 제한)
- **시행령 제18조** — 생체정보·건강정보 범위

### 구조
- **A. 보호자용** — 본인 얼굴 사진(프로필)에 대한 선택 동의
- **B. 입소자 본인/법정대리인용** (핵심) — 얼굴 벡터·건강 메모 수집·이용
- **C. 시설 담당자 확인란** — 법정대리인 자격 검증

### 체크 항목 (3개)
1. 얼굴 사진 및 특징 벡터 수집·이용 (☐ 동의 ☐ 거부)
2. 건강 메모 수집·이용 (☐ 동의 ☐ 거부)
3. 민감정보 국외 이전 (백업 목적, 암호화 상태) (☐ 동의 ☐ 거부)

### 거부 시 영향 고지
- 얼굴 인식 자동 분류 불가 → **수동 분류로 서비스 계속 이용 가능** (거부 불이익 최소화 설계)
- 건강 메모 작성 제한

### 철회 경로
- 서비스 내 "개인정보 설정" 또는 시설 담당자 경유
- **30일 이내** 파기 완료 + 확인 메시지

### 법무 검토 요청 사항 (5건)
1. **법정대리인 자격** (최중요) — 치매 입소자, 성년후견인 없는 경우 가족 중 누가 동의 가능한가
2. 얼굴 벡터의 민감정보 해당성 (개보위 해석 추세는 민감정보로 보는 경향)
3. 동의 거부 시 "자동 분류 불가"가 부당한 거부 불이익이 되는지
4. 건강 메모의 의료법상 "진료기록" 해당성 배제 (돌봄 참조용 선 긋기)
5. 철회 시 파기 기간 30일이 개보위 권장(즉시~5일) 대비 합리적인지

### 이중 구조 설계 제안
법정대리인 논란이 있어 제안:
1. 입소자 측 동의서 (본인/법정대리인)
2. + 시설 담당자 "법정대리인 자격 확인" 서명 (C란)

본 DB에 두 서명 모두 기록 → 추후 감사 대응.
